# THE WORLD TODAY — Tuesday, 17 November 2026

A one-page newspaper front page summing up Tuesday 17 November 2026 in
40 stories from six continents: the Kerch Bridge span falls, fire in the
Gulf as Iran and the US clash, Nvidia's $115bn revenue, plus a world map
with ten flashpoints and the day's markets, tech and sport.

Entry for [news-image-20261117](https://make.fun/bounty/news-image-20261117)
on [make.fun](https://make.fun/bounty/news-image-20261117).

## The image

Drawn programmatically with Python (stdlib only, hand-rolled PNG encoder
and a 5×7 bitmap font) — no AI image generator, so every word is sharp
and legible:

- **Masthead:** THE WORLD TODAY — Tuesday, 17 November 2026, 40 stories, six continents, one front page.
- **Lead panels:** KERCH BRIDGE SPAN FALLS (illustrated) and FIRE IN THE GULF (Iran–US clash).
- **Map:** schematic world map with 10 numbered pins — "WHERE IT HAPPENED".
- **Numbers strip:** $115BN NVIDIA REVENUE • 40 STORIES ON PAGE • 6 CONTINENTS • 2 FLASHPOINTS.
- **Grid:** 38 numbered stories across six continents.

## Run it

```
python3 main.py
```

writes `entry.png` (1024×1024, ≤1 MiB) to `/output`.
